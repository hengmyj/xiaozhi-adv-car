# 页面介绍与操作

共 **1 个主页 + 1 个启动器 + 9 个分页面**。全局随时：**Fn+1** 回小智，**Fn+2** 回启动器。Fn 是键盘左下独立键，不是 Opt。

```
Fn+1 小智主页
Fn+2 启动器 ──1── Car 麦轮
              ├─2── Spider 蜘蛛
              ├─3── IceBox 空调
              ├─4── Clock 时钟
              ├─5── Rain 字幕
              ├─6── Music 拾音
              ├─7── Radio 电台
              ├─8── Snake 贪吃蛇
              └─9── Dino 小恐龙
```

---

## 小智主页（Chat）

上游 xiaozhi 聊天 UI：表情、状态栏、语音对话。开机默认页。代码是 `PageManager` 里的 `ChatPage`，没有自己的 LVGL panel，`ShowChatUi()` / `HideChatUi()` 控制显隐。

| 操作 | 作用 |
|------|------|
| BOOT 短按 | 开机过程中进配网；平时切换聆听/说话 |
| Enter | 同 BOOT，切换聊天状态 |
| ; / ↑ | 音量 +（两端 1% 步进，中间 10%） |
| . / ↓ | 音量 - |
| / / → | 背光 +（最低 30%） |
| , / ← | 背光 - |
| 配网时 **W** | 扫网列表 + 输密码 |
| 配网时 **S** | 已存 WiFi 列表 |

机上配网（`wifi_config_ui`）用 overlay，不会 `lv_obj_clean` 整屏。列表里 `;` `.` 上下，Enter 选中，ESC 取消，密码界面可直接打字。

离开去分页面时聊天 UI 只隐藏不销毁。从 Radio / Music 回来会异步重建 Opus，等页面已经显示再恢复，避免在拆页过程中 `RecycleDevice` 把堆打碎。

---

## 启动器（Launcher）

Sparks 风格 3×3 菜单。顶栏：点阵镂空 **M + YJ** logo、中间系统时间 `HH:MM:SS`（SNTP）、右侧固件版本（如 `v2.2.6`）+ WiFi 图标。标签用 ASCII，避免内置字体缺汉字乱码。

| 键 | 徽章色 | 页面 |
|----|--------|------|
| **1** | 金 | Car 麦轮小车 |
| **2** | 紫 | Spider 蜘蛛 |
| **3** | 蓝 | IceBox 三菱空调 |
| **4** | 绿 | Clock 像素时钟 |
| **5** | 青绿 | Rain 字幕下落 |
| **6** | 青 | Music 拾音柱 |
| **7** | 亮绿 | Radio 网络电台 |
| **8** | 红 | Snake 贪吃蛇 |
| **9** | 橙 | Dino 小恐龙 |

无页内其它操作。离开时默认只隐藏（再进启动器可复用）；进 Snake / Dino / Radio 会拆掉，给游戏对象和 MP3 腾连续内存。

---

## 1 · Car 麦轮小车

MQTT 遥控麦轮。左侧速度环（0–100）和数字，右侧皮卡侧视动画（轮毂会转），底栏运行灯 + 左右方向，顶栏标题「麦轮小车」和 MQTT 信号塔。

| 操作 | 作用 |
|------|------|
| **;** / ↑ | 前进 `car/cmd` `run=1` |
| **.** / ↓ | 停止 `run=0`，方向回中 |
| **,** / ← | 左转 `foc/cmd` `dir=1` |
| **/** / → | 右转 `dir=-1` |

速度用最近一次 `car/state`（连着且有效）否则用本地默认 30。绿灯跑、粉灯停。切回 Chat 若还在跑会自动停。

和 Spider / IceBox 互切时仪表盘保留；去启动器 / Chat / 游戏 / 电台时 Destroy。

---

## 2 · Spider 蜘蛛

同一套 `VehicleControlPage`，场景换成蜘蛛腹+头+四腿摆动。按键、MQTT topic、进出页规则与 Car 完全相同。标题「蜘蛛」。

---

## 3 · IceBox 三菱空调

红外遥控 **三菱电机 ZFJ 系列 MSZ-ZFJ12VA**（KFR-36GW/BpU）。协议默认 `MITSUBISHI_AC`，GPIO 44 发两遍。人眼看不见红外，看左上角粉色 TX 点。

左栏：温度、ON/OFF、MJ logo；右栏 6 个键位按钮，按下去会闪一下。

| 操作 | 作用 |
|------|------|
| **P** | 电源 |
| **M** | 模式循环：制冷 → 制热 → 除湿 → 送风 → 自动 |
| **F** | 风速循环：自动 → 最小 → 低 → 中 → 高 → 最大 |
| **;** / ↑ | 温度 +1（16–30℃） |
| **.** / ↓ | 温度 -1 |
| **S** / Enter / 空格 | 强制重发当前状态 |

每次按键立刻改 UI 并排队发红外，**不用 Enter 确认**。发码在独立 worker，OnLeave 先 `ir_.Cancel()` 再切页，避免 bit-bang 饿死 LVGL。

---

## 4 · Clock 像素时钟

一块 182×54 RGB565 canvas（静态 BSS，不占堆）画 5×7 点阵：上行 `HH:MM:SS`，下行 `YYYY-MM-DD`。时间来自 SNTP 系统钟。

无页内按键。每秒刷新一次。离开立刻 Destroy panel（像素缓冲在 BSS，对象释放即可）。

---

## 5 · Rain（Matrix）

黑客帝国风字幕雨。半分辨率 120×68 canvas + 2× zoom 铺满 240×135，约 16KB BSS。12 列 × 9 行，字带 7 格淡出拖尾，字符来自 A–Z / 0–9 / `@#$%&*`。

无页内按键。离开立刻 Destroy。不要改成「每格一个 lv_label」——上百个对象会把无 PSRAM 堆吃光。

---

## 6 · Music 拾音柱

24 根柱状图，ES8311 麦克风。进页关掉唤醒/语音处理，独占 I2S 输入；512 采样做简单分频后画柱，高峰偏青/绿。

无页内按键，对着麦说话或放音乐即可。

离开必须：停 Tick → 等正在进行的 `CaptureMic` 结束 → 关麦 → `free mic_buf_` → Destroy 24 根柱。不能只 Hidden：Music→启动器→Radio 会叠三套 UI，电台 MP3 会 `MEM_LACK`。

实现文件仍叫 `pages/cursor/`（`CursorPage`），真正的 Cursor 以后再做。

---

## 7 · Radio 网络电台

纯 HTTP MPEG1 Layer III，64kbps。无 HLS、无 TS 播流、无 TLS（握手要额外 8–10KB 任务栈）。进页先释放 Opus 再 BuildPanel，开流 `Schedule` 到主循环。

| 操作 | 作用 |
|------|------|
| **1** / **N** / **,** | 台 0：CNR1 中国之声 |
| **2** / **M** / **/** | 台 1：北京音乐广播 FM974（默认） |
| **P** / 空格 | 暂停 / 继续 |
| **;** / ↑ | 音量 +5 |
| **.** / ↓ | 音量 -5 |

画面：台名、状态（connecting / playing / paused / error）、音量、24 根频谱柱。

离开：作废本轮 `enter_gen_`（防止迟到的 StartStream 又拉起来）→ 关 HTTP 解开阻塞 → 等流任务自己退出 → DestroyPanel。Opus 等到 Fn+1 回 Chat 且页面出来后再重建。

进 Radio 会 sweep 掉其它所有独占页。细节与踩坑见仓库 [docs/audio/radio.md](../../../../docs/audio/radio.md)。

---

## 8 · Snake 贪吃蛇

16×9 全屏格子，每格 15px = 240×135。蛇身用 lv_obj，**不用 canvas**。步进 180ms。

| 操作 | 作用 |
|------|------|
| Enter / 空格 | Ready 开局；Dead 重开；Paused 继续 |
| **P** | 暂停 / 继续 |
| **;** / W / ↑ | 上（Ready 时顺便开局） |
| **.** / S / ↓ | 下 |
| **,** / A / ← | 左 |
| **/** / D / → | 右 |

不能 180° 掉头（队列方向）。吃到食物加长、分数 +1；撞墙或撞自己 Game Over。HUD 显示分数和阶段。

离开立刻 Destroy。从启动器进来时会先拆启动器，避免 ~10KB 菜单加上百个格子对象把堆顶满。

---

## 9 · Dino 小恐龙

跑酷。Ready / Dead 正中显示 120×90 小孩头像（`kid_face_icon.h` 里 RGB565，flash 直读，无运行时解码）。开跑后头像隐藏。

```
DINO 123      00:45        SPD 5.6
(分数·左)   (计时·顶中)  (速度·右)
                      ✧ (☀) ✧     太阳缓慢漂浮
                   ⌣⌣⌣            海鸥，5–15s 飞过一只
          ▲
         / \                      杉树滚来，随分数加速
    ═══════════════════
      🦖 (蹬腿)                   空格/↑ 跳跃
```

| 操作 | 作用 |
|------|------|
| 空格 / Enter / W / ↑ / J | Ready 开跑；Dead 重开；Running 跳跃 |
| **P** | 暂停 / 继续 |

跳跃有短促「嘀」（C5）；撞树「哔—呜」；Running 时 C 大调琶音循环，离开 `StopMusic()`。计时只在 Running 走，暂停/死亡冻结。速度随分数从 3.2 往上加。碰撞是 AABB。

离开立刻 Destroy panel + 停音乐任务。头像数据在 `.rodata`，不占堆；加新图请看 [images.md](images.md)。
