## 像素图标版（LVGL，不加载 PNG）

生成的头文件：`main/boards/m5stack-cardputer-adv-car/common/kid_face_icon.h`

- 64×29 RGB565 像素数组（`kKidFaceIconData`）+ LVGL 描述符 `kKidFaceIcon`
- 透明区域填 Dino 页背景色 `0x0A0A12`，直接贴深色背景看不出黑块
- 无 PNG 解码、无外部资源，纯常量数据

LVGL 用法（任意页面）：

```cpp
#include "kid_face_icon.h"

lv_obj_t* icon = lv_image_create(parent);
lv_image_set_src(icon, &kKidFaceIcon);
lv_obj_set_pos(icon, x, y);
```

重新生成（换尺寸/背景色/裁剪）：

```bash
python3 /tmp/gen_icon.py   # 脚本内改 W / 背景色 / 裁剪比例
```
